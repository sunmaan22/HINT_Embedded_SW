# Embedded System Interface Circuits

MCU와 센서·스위치·통신 버스·부하 사이의 전기적 연결을 정리한 기술 노트이다. 각 회로는 **무엇을 연결하는지**, **어떤 조건을 맞추는지**, **소프트웨어 제어와 고장 진단에 어떻게 이어지는지**를 중심으로 설명한다.

## 2. 자동차 인터페이스 회로의 역할

차량의 배터리 전압은 시동·충전·부하 변화에 따라 달라지고, 하니스에는 잡음과 접지전위 차이가 존재한다. MCU의 논리 신호를 외부 배선에 연결하는 문제와 MCU 내부 레지스터를 설정하는 문제는 함께 다루어야 한다.

| 인터페이스 | 연결 대상 | 주요 역할 | SW와 연결되는 정보 |
|---|---|---|---|
| 전원 | 배터리와 ECU 내부 전원 | 전압 변환, 과도현상 대응, 전원 감시 | 전원 정상 여부, 리셋 원인, 저전압 상태 |
| 디지털 입력 | 버튼·스위치·펄스 센서 | 논리 레벨 변환, 기본 상태 설정, 입력 보호 | GPIO 상태, 에지, 유효 이벤트 |
| 아날로그 입력 | 온도·압력·위치·전류 센서 | 증폭·분압·필터링과 ADC 연결 | 원시 코드, 물리량, 유효성 |
| 출력 | LED·릴레이·모터 등 | 제어 신호를 부하 구동으로 변환 | 출력 명령, 듀티, 피드백 |
| 통신 | CAN·LIN 등 외부 버스 | 물리 계층 송수신과 버스 상태 처리 | 메시지, 오류, 슬립·웨이크업 |
| 절연 | 서로 분리된 전기적 영역 | 직접적인 도전 경로를 끊고 정보 전달 | 절연된 측정값·명령·진단 |

**CAN 컨트롤러와 트랜시버는 역할이 다르다.** 컨트롤러는 프레임과 프로토콜 처리를 담당하고, 트랜시버는 버스의 전기적 신호를 송수신한다. MCU의 CAN 송수신 핀과 CAN_H·CAN_L은 같은 종류의 신호가 아니다.

통신 종단과 필터도 버스 구조의 일부이다. 종단은 네트워크 끝점과 배선 구조를 기준으로 판단하며, 모든 노드에 같은 저항을 추가하는 방식으로 이해하지 않는다.

## 3. 기초 소자와 보호 소자

소자의 이름을 외우는 것보다 저장하는 에너지, 전류 경로, 동작 조건과 손실을 구분하는 것이 중요하다.

### 수동 소자

| 소자 | 기본 관계 | 인터페이스에서의 역할 | 실제 소자에서 고려할 점 |
|---|---|---|---|
| 저항 R | `V = IR`, `P = I²R` | 분압, 전류 제한, 풀업·풀다운 | 오차, 정격 전력, 온도 변화 |
| 인덕터 L | `v = L × di/dt` | 전류 변화 억제, 필터의 에너지 저장 | 권선 저항, 포화, 기생 성분 |
| 커패시터 C | `i = C × dv/dt` | 디커플링, 전압 변화 완화, 필터 | ESR·ESL, 실효 용량, 정격과 극성 |

이상적인 인덕터와 커패시터의 리액턴스 크기는 각각 `2πfL`, `1/(2πfC)`이다. 실제 부품에서는 기생 성분 때문에 이 관계가 모든 주파수에 그대로 적용되지 않는다.

### 보호·스위칭 소자

| 소자 | 주요 역할 | 구분해야 할 조건 |
|---|---|---|
| 일반 다이오드 | 정류와 전류 경로 형성 | 순방향 전압은 전류·온도·종류에 따라 달라진다. |
| 제너 다이오드 | 역방향 항복 영역을 활용한 전압 기준·제한 | 동작 전류와 전력 소모를 함께 본다. |
| TVS | 과도전압에 대한 클램핑 | 정상 전압, 클램프 전압, 펄스 파형·에너지와 정전용량을 구분한다. |
| 바리스터 | 비선형 전압 특성을 이용한 서지 억제 | 정전용량, 에너지 정격, 반복 스트레스가 영향을 준다. |
| RC 스너버 | 스위칭 과도현상과 링잉 완화 | 부하·배선과 함께 응답이 결정된다. |
| 페라이트 | 특정 주파수 영역의 잡음 감쇠 | 주파수별 임피던스와 DC 바이어스 조건을 본다. |
| BJT·MOSFET | 작은 제어 신호로 부하 전류 제어 | 구동 조건, 손실, 온도와 정격을 함께 검토한다. |
| 릴레이 | 코일의 자기 작용으로 접점 전환 | 코일과 접점의 사양·동작 시간이 서로 다르다. |

TVS를 특정한 짧은 시간의 펄스에만 쓰는 소자로 단정하지 않는다. 처리 가능한 과도현상은 제품의 펄스 정격과 회로 조건으로 판단하며, 지속적인 과전압까지 항상 해결하는 소자는 아니다. 보호 소자의 단방향·양방향 선택도 신호의 극성과 인터페이스 조건에 따라 달라진다.

## 4. 아날로그·디지털·PWM 신호

| 구분 | 정보를 표현하는 방법 | 대표 처리 | 주의할 점 |
|---|---|---|---|
| 아날로그 | 전압·전류 등의 연속적인 크기 | 증폭, 필터, ADC | 잡음·오프셋·기준전압이 측정값에 반영된다. |
| 디지털 | 정해진 논리 범위와 시간 관계 | GPIO, 인터럽트, 직렬 통신 | 중간 전압 영역은 논리 상태가 보장되지 않을 수 있다. |
| PWM | 주기 내 활성 시간의 비율 | 타이머 출력, 듀티 조절 | 전압 크기와 듀티를 구분하고 출력 극성을 확인한다. |

디지털 신호도 실제 배선에서는 연속적인 전압 파형이다. 상승·하강 시간, 링잉, 임계값과 잡음 여유가 디지털 판정에 영향을 준다.

PWM의 듀티는 `D = T_on / T`, 주파수는 `f = 1/T`이다. 이상적인 0 ~ V 전압 펄스의 평균은 `D × V`이지만, 모터의 회전속도나 LED의 체감 밝기가 듀티에 언제나 정확히 비례한다는 뜻은 아니다.

## 5. MCU 핀의 전기적 특성

하나의 핀은 멀티플렉서 설정에 따라 GPIO·ADC·PWM·통신 기능으로 사용될 수 있다. 핀 기능 선택과 전기적 사용 가능 조건은 별도로 확인한다.

| 확인 항목 | 의미 | 소프트웨어와의 관계 |
|---|---|---|
| Pin MUX·패키지 | 실제 핀과 주변장치의 연결 | 대체 기능과 입력·출력 방향 설정 |
| 전원 도메인 | 코어·I/O·아날로그 전원의 구분 | 초기화 순서와 전원 상태 관리 |
| VIH·VIL | 입력 High·Low 판정의 보장 조건 | GPIO의 0·1 해석 |
| VOH·VOL | 지정 부하에서 보장되는 출력 전압 | 외부 입력과 논리 레벨 호환 |
| 출력 전류 | 핀·포트·칩 전체의 전류 제한 | 동시 출력 조건과 구동 강도 |
| 누설·내부 Pull | 입력 전류와 기본 상태 | 미사용 핀·슬립 설정 |
| ADC 획득 시간 | 내부 샘플 커패시터의 충전 시간 | 샘플링 시간과 채널 전환 설정 |
| 리셋·부트 상태 | 초기화 전 핀의 상태 | 부팅 중 의도하지 않은 출력 방지 |
| 전원 OFF 특성 | 무전원 상태에서 외부 입력 허용 여부 | 전원 시퀀스와 외부 장치 제어 |

논리 레벨 호환성은 송신측의 `VOH(min)`이 수신측 `VIH(min)` 이상이고, 송신측 `VOL(max)`가 수신측 `VIL(max)` 이하인지 확인하는 방식으로 검토한다. 입력 허용전압 조건도 별도로 만족해야 한다.

### 절대최대 정격과 Back-Powering

**절대최대 정격은 정상 동작이나 정확도를 보장하는 범위가 아니다.** 권장 동작조건, DC·AC 특성과 함께 읽어야 한다.

MCU 전원이 꺼진 상태에서 외부 입력이 들어오면 내부 보호 경로를 통해 전원 레일에 전류가 유입될 수 있다. 이를 Back-Powering이라고 하며, 부분적인 전원 인가·리셋 불안정·대기전류 증가로 이어질 수 있다. 오픈드레인이라는 이유만으로 자동 해결되지는 않으며 풀업 전원의 도메인까지 확인한다.

## 6. 디지털 입력과 출력 회로

디지털 입력은 외부 상태를 MCU 논리로 바꾸고, 디지털 출력은 MCU 명령을 부하에 전달한다. 입력에 필요한 잡음 여유와 출력에 필요한 구동 능력은 서로 다르다.

| 구분 | 회로의 역할 | 프로그램이 다룰 항목 |
|---|---|---|
| 입력 보호 | 외부 이상 전압의 영향 제한 | 입력 유효 여부와 진단 상태 |
| 레벨 변환 | 외부 전압을 MCU 논리 범위에 맞춤 | 활성 극성과 논리 해석 |
| 풀업·풀다운 | 열린 입력의 기본 상태 결정 | 초기 상태와 버튼 해제 상태 |
| 필터·히스테리시스 | 짧은 잡음과 임계값 부근 흔들림 완화 | 에지 검출·디바운싱 |
| 출력 드라이버 | GPIO와 부하의 전류·전압 차이 해결 | Enable, 출력 명령, PWM |
| 피드백 | 명령이 실제 결과로 이어졌는지 확인 | 명령·측정 비교와 고장 판단 |

**Dry Contact**는 자체 전압 신호를 공급하지 않는 접점이고, **Wet Contact**는 외부에서 전압이 인가되는 접점 신호를 뜻하는 문맥으로 사용한다. 이름만으로 입력 회로를 결정하지 않고 실제 전압·전류 조건을 확인한다.

Push-Pull 출력은 High와 Low를 모두 능동적으로 구동한다. Open-Drain·Open-Collector 출력은 한 방향으로 전류를 끌어내리는 구조이며, 반대 논리 상태는 풀업 등의 외부 조건에 의해 만들어진다.

## 7. 풀업·풀다운·디바운싱

### 기본 상태와 Pull 저항

Floating 입력은 외부에서 논리 상태가 충분히 정해지지 않은 입력이다. 주변 잡음이나 누설전류로 판정이 달라질 수 있다.

| 방식 | 스위치가 열렸을 때 | 대표적인 논리 해석 |
|---|---|---|
| 풀업 | High | GND로 연결되는 스위치가 닫히면 Active-Low |
| 풀다운 | Low | 전원 쪽으로 연결되는 스위치가 닫히면 Active-High |

Pull 저항이 작으면 누설·잡음에 대한 여유가 커질 수 있지만 활성 상태의 전류가 증가한다. 너무 크면 누설과 기생 커패시턴스의 영향을 크게 받는다. 내부 Pull은 값의 범위와 리셋·슬립 중 상태도 함께 확인한다.

### 버튼 상태와 이벤트의 차이

기계 접점은 한 번 조작해도 짧은 시간 동안 여러 번 전환될 수 있다. **입력 레벨**, **안정된 버튼 상태**, **눌림·해제 이벤트**를 분리하면 이를 다루기 쉽다.

| 방법 | 동작 | 특성 |
|---|---|---|
| 지연 후 재확인 | 일정 시간 뒤 다시 읽음 | 단순하지만 블로킹 지연은 다른 작업을 늦출 수 있다. |
| 주기 샘플링 | 같은 값이 연속 유지되는지 확인 | 실행 주기와 카운터로 판정 시간을 관리한다. |
| RC 필터 | 빠른 전압 변화를 완화 | 응답 지연과 임계값을 함께 고려한다. |
| 슈미트 트리거 | 상승·하강에 서로 다른 임계값 사용 | 느린 에지와 임계값 주변 흔들림에 대응한다. |
| 하드웨어 글리치 필터 | 짧은 펄스를 주변장치가 걸러냄 | 지원 기능과 시간 설정은 MCU마다 다르다. |

주기 샘플링의 명목 판정 시간은 `T_debounce ≈ N × T_sample`이다. 1 ms마다 20회 연속 확인하면 약 20 ms 기준이 되며 실제 입력 발생 시점과 태스크 지터에 따라 지연이 달라진다.

눌림뿐 아니라 해제도 안정된 뒤 상태를 바꾸어야 반복 토글을 줄일 수 있다. 인터럽트는 원시 에지를 포착하는 수단이며 디바운싱 자체를 대신하지 않는다.

## 8. LED·스위치 실습과 상태기계

강의의 실습은 LED 출력을 시작으로 버튼 입력, 이벤트 처리, PWM, 피드백 진단을 단계적으로 통합하는 구성이다.

| 단계 | 학습 내용 | 확인할 결과 |
|---|---|---|
| GPIO 출력 | LED 출력과 활성 극성 | 논리적인 켜짐·꺼짐과 핀 레벨의 대응 |
| GPIO 입력 | 스위치 상태 읽기 | 열린 상태와 닫힌 상태의 안정성 |
| 입력·출력 연결 | 버튼으로 LED 제어 | 상태 유지와 에지 토글의 차이 |
| 디바운싱 | 연속 샘플 판정 | 한 번 조작에 한 번의 유효 이벤트 |
| 인터럽트 | 이벤트 포착과 처리 분리 | ISR 길이와 이벤트 유실 여부 |
| PWM | 밝기 단계 조절 | 듀티·주파수·극성의 관계 |
| Mini BCM | 상태기계와 피드백 통합 | 명령·출력·고장 상태의 일관성 |

ISR에서는 필요한 정보만 기록하고, 상태 전환·표시·로그 처리는 메인 루프나 태스크가 담당하도록 역할을 나눈다. 이벤트 플래그는 같은 이벤트가 연속 발생하면 하나로 합쳐질 수 있으므로 발생 횟수나 순서가 중요하면 카운터·큐를 검토한다.

### 상태기계의 예

| 상태 | 주요 동작 | 전환 조건의 예 |
|---|---|---|
| OFF | 소등 명령 유지 | 유효한 켜기 이벤트 |
| ON | 설정된 밝기 출력 | 끄기 이벤트 또는 밝기 변경 |
| FAULT | 정해진 고장 출력·표시 정책 수행 | 명령과 피드백의 불일치가 판정 기준을 만족 |
| 복귀 판단 | 원인 해제·재시작 조건 확인 | 명시된 복귀 조건 만족 |

이 표는 설계 개념이며 저장소에 구현된 상태기계라는 의미는 아니다. LED 명령이 ON인데 피드백이 없다는 이유만으로 즉시 특정 고장을 확정하지 않고, 출력 응답 시간·측정 지연·유효 측정 구간을 함께 고려한다.

## 9. 아날로그 센서와 신호 조정

센서의 물리량은 전압·전류·저항·차동 신호 등으로 표현된다. **Signal Conditioning**은 이 신호를 ADC가 측정하기 적합한 범위와 대역으로 바꾸는 과정이다.

| 센서 출력 | 입력 회로의 역할 | 변환 시 확인할 점 |
|---|---|---|
| 전압 | 분압·버퍼·필터 | 센서 최대 출력과 ADC 범위 |
| 전류 | 저항 등을 이용한 전압 변환 | 변환 이득과 전력·허용전압 |
| 저항 | 분압 등으로 저항 변화를 전압화 | 비선형성, 저항 오차, 센서 자체 발열 |
| 차동 | 두 입력의 차이를 증폭 | 공통모드 범위와 공통모드 제거 성능 |

선형 조정의 개념은 `V_ADC = G × V_sensor + V_offset`이다. 이득으로 ADC 범위 활용도를 높이고, 오프셋으로 기준점을 옮기며, 필터로 필요한 대역 밖의 성분을 줄인다.

OP 앰프는 이상적인 증폭기로만 보지 않는다. 입력 공통모드 범위, 출력 스윙, 대역폭, 오프셋과 부하 구동 조건이 실제 측정 범위를 제한한다.

### 정상 범위와 진단 범위

일부 센서는 전원 레일 사이의 전체 범위를 쓰지 않고 정상 신호 구간 양 끝에 여유를 둔다. 이 여유는 범위 이탈 진단에 활용할 수 있다.

다만 낮은 ADC 코드가 항상 GND 단락이고 높은 코드가 항상 배터리 단락인 것은 아니다. 단선 시 전압은 바이어스 회로에 따라 달라지며, 필터·클램프·센서 고장도 같은 코드로 나타날 수 있다. 범위 검사, 지속시간, 변화율과 다른 측정값의 일관성을 조합한다.

## 10. ADC 입력 범위·분해능·정확도

| 항목 | 의미 |
|---|---|
| 입력 범위 | 변환 특성이 규정되는 아날로그 전압 범위 |
| 분해능 | 출력 코드의 단계 수 |
| 정확도 | 측정값이 실제 값에 가까운 정도 |
| 샘플링 속도 | 단위 시간당 변환하는 횟수 |
| ENOB | 잡음·왜곡을 반영한 실효 동적 성능 지표 |
| 오프셋·이득 오차 | 기준점과 변환 기울기의 오차 |
| INL·DNL | 이상적인 변환 특성과 코드 간격에서의 편차 |

### 핵심 계산

N비트 단극성 ADC의 이상적인 코드 범위는 `0 ~ 2^N - 1`이고, 양자화 간격은 다음과 같다.

`LSB = (V_REFH - V_REFL) / 2^N`

| 분해능 | 기준 범위 | 코드 범위 | 이상적인 1 LSB |
|---|---|---|---|
| 10 bit | 0 ~ 5 V | 0 ~ 1023 | 약 4.883 mV |
| 12 bit | 0 ~ 5 V | 0 ~ 4095 | 약 1.221 mV |
| 12 bit | 0 ~ 3.3 V | 0 ~ 4095 | 약 0.806 mV |

코드에서 전압으로 복원하는 단순 근사는 `V_in ≈ V_REFL + code × LSB`이다. 실제 변환식의 코드 경계·반올림·끝점 정의는 ADC의 전달 특성을 따른다. 끝점 보정에 사용하는 `2^N - 1`과 양자화 간격의 `2^N`을 혼동하지 않는다.

선형 센서의 두 교정점이 `(V1, X1)`, `(V2, X2)`라면 물리량은 다음과 같이 환산할 수 있다.

`X = X1 + (V - V1) × (X2 - X1) / (V2 - V1)`

### 샘플링과 기준전압

ADC 입력에는 내부 샘플 커패시터가 있으므로 소스 임피던스가 높거나 획득 시간이 짧으면 충분히 충전되지 않을 수 있다. 필터 저항, 센서 출력 임피던스, 채널 전환과 ADC 샘플링 시간은 함께 결정한다.

Ratiometric 측정에서는 센서 출력과 ADC 기준이 같은 공급전압에 비례하도록 구성하여 공통적인 전원 변동의 영향을 줄인다. 배선 전압강하나 서로 다른 경로의 잡음까지 자동으로 사라지는 것은 아니다.

평균과 오버샘플링은 조건이 맞을 때 잡음에 따른 변동과 유효 분해능을 개선할 수 있다. 이상적인 조건에서 추가 n비트를 얻는 데 약 `4^n`개 샘플이 필요하지만, 충분한 잡음·대역 제한과 적절한 누산·스케일링이 전제이다. 기준전압 오차와 비선형 오차는 단순 평균으로 없어지지 않는다.

## 11. 필터링·접지·노이즈와 PCB

노이즈는 **발생원**, **전달 경로**, **영향을 받는 회로**로 나누어 분석한다. 모터 PWM과 ADC 흔들림이 동시에 나타난다면 입력 코드뿐 아니라 전원·접지·기준전압 경로의 관계를 살펴야 한다.

| 구분 | 의미 | 분석 관점 |
|---|---|---|
| 전도 | 전원·신호선 등 도전 경로로 전달 | 어느 선으로 들어오고 어디로 돌아가는가 |
| 방사 | 공간의 전자기장을 통해 결합 | 배선·루프·차폐가 어떤 영향을 주는가 |
| 차동 모드 | 두 선 사이의 차로 나타나는 성분 | 유효 신호와 같은 경로의 잡음인가 |
| 공통 모드 | 두 선에 공통으로 나타나는 성분 | 기준점·하니스·공통모드 범위는 어떠한가 |
| 공통 임피던스 결합 | 공유 경로의 전압강하가 다른 회로에 영향 | 부하 전류와 센서 리턴이 경로를 공유하는가 |

### 필터와 디커플링

| 방법 | 목적 | 한계와 고려 사항 |
|---|---|---|
| RC 저역통과 | 빠른 변화 감쇠 | 응답 지연과 ADC 획득 시간 증가 |
| LC·π 필터 | 전원 잡음 감쇠 | 부하·기생 성분에 따른 공진과 감쇠 |
| 페라이트 비드 | 특정 고주파 대역 감쇠 | 전류에 따른 특성 변화 |
| 디커플링 | IC의 순간 전류를 가까운 위치에서 공급 | 용량뿐 아니라 배치와 연결 인덕턴스 |
| 공통모드 초크 | 공통모드 성분 감쇠 | 신호 대역과 기생 성분의 영향 |

이상적인 RC 필터의 차단주파수는 `f_c = 1/(2πRC)`이다. `R = 1 kΩ`, `C = 100 nF`이면 약 1.59 kHz이며, 실제 회로에서는 앞뒤 임피던스도 반영한다.

LC의 `1/(2π√(LC))`는 기본 공진 주파수 관계이다. 실제 필터의 차단 특성과 피킹은 종단·손실·감쇠에 따라 달라지므로 이 숫자 하나로 필터 성능을 확정하지 않는다.

### 접지는 리턴 경로이다

접지에도 저항과 인덕턴스가 존재한다. 고주파 리턴 전류가 참조면의 틈을 우회하면 신호 루프가 커질 수 있다. 따라서 아날로그·디지털 회로를 구분할 때는 명칭에 따라 무조건 접지면을 자르기보다 실제 전류 경로와 IC의 레이아웃 지침을 고려한다.

스타 접지는 특정 저주파·고전류 구조에서 공유 경로를 줄이는 데 유용할 수 있지만 모든 주파수와 보드에 통용되는 해법은 아니다. 디커플링 역시 특정 용량 하나로 모든 잡음을 해결하지 않으며 ESR·ESL·자기공진과 전원망의 상호작용을 함께 본다.

절연은 직접적인 도전 경로를 분리하는 방법이고, 클램핑은 과도전압을 제한하는 방법이다. 차폐·필터링·절연·보호 소자는 서로 같은 기능이 아니다.

## 12. 부하 구동·트랜지스터·MOSFET·릴레이

MCU 출력은 부하 동작을 지시하는 신호이다. 구동부는 그 명령을 받아 전류를 제어하고, 측정·진단 회로는 실제 동작 결과를 MCU에 되돌린다.

### 구동 구조 비교

| 구조 | 개념 | 주요 고려 사항 |
|---|---|---|
| Low-Side | 부하의 접지 쪽 경로를 제어 | 부하 기준점과 배선 고장 시 경로 |
| High-Side | 부하의 전원 쪽 경로를 제어 | 소스 기준의 게이트 구동과 전원 상태 |
| Half-Bridge | 상·하단 스위치로 출력 노드 제어 | 동시 도통 방지와 전류 경로 |
| H-Bridge | 두 Half-Bridge로 부하 양단 제어 | 방향·제동 상태와 피드백 |
| Smart Switch | 구동·감시·보호 기능 통합 | 제한 전류, 오류 보고와 복귀 정책 |

### 소자별 특징

BJT 스위치에서는 활성영역의 전류이득만으로 포화 상태를 보장할 수 없다. 베이스 구동 조건과 포화 전압을 확인하며, 대표적인 도통 손실 근사는 `P ≈ V_CE(sat) × I_C`이다.

MOSFET의 **V_GS(th)는 작은 전류가 흐르기 시작하는 조건**이다. 충분한 부하 전류를 낮은 손실로 흘릴 수 있다는 보증이 아니다. 실제 게이트 전압에서의 R_DS(on) 보장 조건과 온도 영향을 확인한다. 도통 손실은 켜져 있는 구간에서 `P ≈ I_D² × R_DS(on)`으로 근사하며 PWM 운전에서는 시간 평균과 스위칭 손실도 고려한다.

게이트는 정상상태의 DC 전류가 작더라도 전환할 때 전하의 충·방전이 필요하다. 스위칭을 빠르게 하는 것과 잡음·링잉·손실 사이에는 절충 관계가 있다.

릴레이는 코일과 접점이 서로 다른 사양을 가진다. 코일의 전류 변화, 접점의 바운스·수명과 실제 부하 종류를 나누어 이해한다. MOSFET과 릴레이의 선택은 속도·손실·절연·수명·진단 요구를 함께 비교하는 문제이다.

### 보호와 진단의 관계

| 현상 | 하드웨어 관점 | SW 관점 |
|---|---|---|
| 유도성 부하 차단 | 저장 에너지와 클램프 동작 | 출력 해제 후 응답 시간 |
| 과전류·단락 | 전류 제한·차단 경로 | 고장 기록과 재시도 정책 |
| 과열 | 손실과 열 방출 | 온도 기반 제한과 복귀 조건 |
| 부하 단선 | 명령 대비 피드백 부재 | 유효 측정 시점과 지속시간 |
| 저전압·과전압 | 전원 범위와 보호 상태 | 상태 전환·리셋 원인 처리 |
| 접지 상실 | 예상하지 못한 전류 경로 | 진단 정보의 신뢰성 판단 |

유도성 에너지는 `E = 1/2 × L × I²`로 표현된다. 클램프의 위치와 방식은 회로에 따라 다르므로 특정 연결 한 가지가 모든 경우의 정답이라고 단정하지 않는다. 일반적으로 클램프 수준은 전류 감소 시간과 소자 스트레스에 함께 영향을 준다.

## 13. PWM 모터 제어의 구조

모터 제어는 듀티 값을 쓰는 작업에 더해 전류·위치·속도 피드백을 읽고 다음 출력을 계산하는 폐루프 처리이다.

| 대상·방식 | 핵심 개념 | 필요한 정보 |
|---|---|---|
| 브러시 DC 모터 | 전압·전류와 방향 제어 | 전류, 필요에 따른 속도·위치 |
| BLDC 6-Step | 회전자 위치에 맞추어 통전 상태 전환 | 위치 검출 또는 추정 |
| PMSM FOC | 회전 좌표계에서 전류 성분 제어 | 전류와 회전자 각도 |
| SVPWM | 전압 지령을 상별 듀티로 변환 | 전압 지령과 전원 조건 |

FOC에서 Clarke·Park 변환은 상전류를 제어하기 편한 좌표계로 표현하고, 전류 제어기의 결과는 역변환과 변조를 거쳐 PWM에 전달된다. FOC는 제어 알고리즘이고 SVPWM은 변조 단계이다.

일부 기본 PMSM 제어에서는 d축 전류를 0 부근으로 두지만, 모터 특성과 운전 영역에 따라 최적 전류 지령은 달라진다. 듀티나 q축 전류와 토크의 관계도 모델·운전 조건을 전제로 이해한다.

### 타이밍과 듀티 분해능

| 요소 | 역할 |
|---|---|
| 상보 PWM | 상·하단 제어 신호의 관계 구성 |
| Dead Time | 전환 중 동시 도통을 피하기 위한 시간 |
| Center-Aligned | Up/Down 카운트 기반의 대칭 파형 |
| ADC Trigger | 유효한 전류 측정 시점을 타이머와 연결 |
| Shadow Register | 계산 시점과 출력 반영 시점 분리 |
| 다채널 동기 갱신 | 상별 명령이 같은 경계에서 적용되도록 구성 |
| Fault 입력 | 긴급한 이상 조건에 대한 하드웨어 반응 경로 |

단순한 Edge-Aligned 카운터에서 한 주기의 카운트 수를 N이라 하면 `f_PWM = f_timer / N`이고 듀티 단계는 대략 `1/N`이다. 분주 후 타이머 클럭이 100 MHz이고 PWM이 20 kHz이면 N은 5000, 한 카운트는 약 0.02%이다. Up/Down 모드와 끝점 포함 방식에서는 해당 타이머의 계산식을 적용한다.

PWM 20 kHz의 주기는 50 μs이지만 제어 연산에 50 μs 전체를 쓸 수 있다고 가정하지 않는다. ADC 획득·변환, 데이터 전달, 인터럽트 지연과 다음 출력 갱신 마감까지 포함해 시간 예산을 계산한다.

## 14. 임베디드 SW 계층과 고장 처리

| 계층·기능 | 책임 | 대표 정보 |
|---|---|---|
| 하드웨어 | 변환·구동·보호 | 핀 전압, 전류, Fault 신호 |
| 주변장치 드라이버 | GPIO·ADC·PWM 등 설정과 접근 | 원시 입력, 변환 결과, 출력 설정 |
| 입력 처리 | 디바운스·필터·단위 변환 | 안정된 이벤트와 물리량 |
| 응용 제어 | 상태기계와 제어 알고리즘 | 모드, 목표값, 다음 출력 |
| 진단 | 명령·피드백·시간 조건 비교 | 오류 상태, 원인, 복귀 가능 여부 |
| 통신·표시 | 상태 전달과 외부 명령 수신 | 메시지, 로그, 사용자 표시 |

AUTOSAR 관점에서는 MCAL이 주변장치 접근을 추상화하고, 응용 로직은 상위 계층에서 기능을 구성한다. 고속 모터 제어처럼 여러 주변장치의 정밀 동기가 필요한 경우에는 전용 드라이버·복합 장치 처리와의 경계도 중요하다. 특정 API의 존재만으로 전체 제어 루프가 완성되는 것은 아니다.

빠른 과전류 등의 이상에 대한 하드웨어 반응과, 고장 기록·복귀 판단 같은 SW 처리는 목적과 시간 척도가 다르다. 고장 해제 후 자동 재시작 여부는 응용 요구사항에 따라 명시한다.

## 15. 학습·검증 체크리스트

| 영역 | 확인 질문 |
|---|---|
| 핀 설정 | 회로 연결, Pin MUX, 방향과 활성 극성이 일치하는가 |
| 초기 상태 | 리셋·부팅·슬립 중 입력과 출력이 정의되어 있는가 |
| 논리 호환 | 입력 임계값과 출력 보장 전압을 대조했는가 |
| 버튼 | 눌림과 해제 모두 안정된 이벤트로 처리되는가 |
| ADC | 코드·전압·물리량 변환에서 단위와 범위를 구분하는가 |
| 측정 품질 | 분해능과 정확도, 기준전압과 획득 시간을 구분하는가 |
| PWM | 주파수·듀티·극성·갱신 시점이 요구와 일치하는가 |
| 응답 시간 | 필터·디바운싱·샘플링·태스크 지연을 합산했는가 |
| 진단 | 정상 상태와 고장 상태를 구분할 피드백이 있는가 |
| 오류 처리 | 고장 판정·유지·해제·재시작 조건이 정의되어 있는가 |
| 노이즈 | 발생원과 전달·리턴 경로를 함께 설명할 수 있는가 |
| 계층 분리 | 응용 로직이 하드웨어 세부 접근과 분리되어 있는가 |

공부 순서는 **기초 소자와 핀 특성 → GPIO·스위치 → 디바운싱과 상태기계 → 센서·ADC → 잡음과 리턴 경로 → 구동·PWM → 피드백 진단**으로 연결할 수 있다. 이 문서의 확인 항목은 학습과 설계 검토용이며 실제 검증 결과를 의미하지 않는다.
