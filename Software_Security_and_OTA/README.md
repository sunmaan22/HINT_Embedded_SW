# Software Security and Secure OTA

차량 소프트웨어를 **누가 승인했는지**, **이 ECU에 설치해도 되는지**, **중단되어도 다시 실행할 수 있는지**를 단계별로 확인하는 Secure OTA 학습 노트이다.

[상세 개념](./Fundamentals.md) · [임베디드 SW 관점](./Embedded_SW_Study.md) · [전체 구성도](./Visual_Overview.md) · [실습 코드](./lab/README.md)

## 0. 이 문서가 다루는 범위

| 축 | 핵심 질문 | 주요 수단 |
|---|---|---|
| 무결성 | 받은 바이트가 승인된 이미지와 같은가 | SHA-256 · 청크/전체 해시 |
| 출처와 권한 | 이 배포물을 승인한 키를 신뢰하는가 | HMAC · 전자서명 · PKI · 서명자 승인 목록 |
| 통신 상대 | 지금 접속한 서버가 기대한 서버인가 | TLS 인증서 경로 · SAN · 키 소유 증명 |
| 설치 정책 | 이 대상·HW·보안 세대에 맞는가 | 서명된 매니페스트 · 보안 하한 |
| 실행 승인 | 저장 이후에도 실행 이미지가 승인 상태인가 | Secure Boot · 하드웨어 신뢰 기반 |
| 실패 복구 | 설치·시험 부팅이 실패하면 어디로 돌아가는가 | A/B 슬롯 · 메타데이터 · Health Check |
| 차량 구성 | 각 ECU뿐 아니라 조합과 전환 경로도 허용되는가 | 의존 조건 · 승인 구성 · 캠페인 완료 정책 |

**서명 유효 ≠ 서명자 승인 ≠ 설치 허용 ≠ 정상 동작 ≠ 캠페인 완료**다. 각 단계의 성공을 다음 단계의 성공으로 대신하지 않는다.

## 3. 핵심 예제의 공통 값

| 항목 | 교육용 값 | 의미 |
|---|---|---|
| 작은 이미지 | `b'OTA-DEMO: led=0\n'` | 16바이트 · 인덱스 14 변경 실험 |
| 큰 이미지 | 512 KiB = 524288바이트 | 고정 길이 슬롯·수신 실험 |
| 청크 | 64 KiB = 65536바이트 × 8개 | 청크 2의 범위는 131072~196607 |
| 서명 | Ed25519 | 공개키 32바이트 · 서명 64바이트 |
| 대상 | `ECU-BODY-01` | 단말과 매니페스트의 대상 비교 |
| 보안 버전 | 기존 5 · 후보 6 | 릴리스 문자열과 별개 |
| 시험 부팅 | 최대 3회 | 후보 등록 때 한 번 설정 |

수치는 강의와 실습의 가정값이며 실차 요구사항이나 특정 제조사의 설계를 뜻하지 않는다.

## 4. 원자료와 재구성 범위

- 원자료: **김기윤, 「소프트웨어 보안 / Secure OTA」**, 국립부경대학교 컴퓨터인공지능공학부/정보보호학과, 제공된 `SW보안및OTA_김기윤.pdf`.
- 개념과 실험 조건은 강의를 바탕으로 다시 서술했다. 원본 PDF·개인 연락처·슬라이드 이미지는 이 폴더에 포함하지 않는다.
- PDF에는 `otalab.py`, `mini_ota.py`의 일부 코드와 실행 예가 있으며 완전한 원본 소스는 첨부되지 않았다. **이 저장소의 코드는 강의 개념을 재구현한 독립적인 교육용 코드**다. CLI와 난수 키·해시 출력은 원본과 다를 수 있다.
- 실제로 수행하는 것: SHA-256/HMAC/Ed25519 계산, 인증서 검사와 로컬 TLS 연결, 매니페스트·청크 검사, 파일 기록, 별도 프로세스에서 상태 재읽기, 구성 정책 판정.
- 모의 처리하는 것: ECU 실행·Health Check, 보호 저장소, 단조 증가 보안 상태, 플래시 전원 손실, 차량 설치 전제조건.
- 하드웨어 Secure Boot, HSM/TEE/RPMB, CRL/OCSP, Uptane 전체 프로토콜, 차량 기능안전·형식승인 적합성은 구현·입증 범위 밖이다.

## 5. 먼저 실행하기

```sh
cd Software_Security_and_OTA/lab
python -m pip install -r requirements.txt
python otalab.py hash
python otalab.py package --case normal
python -m unittest -v
```

세부 명령, 예상 결과와 검증 범위는 [실습 안내](./lab/README.md)에 정리했다.
