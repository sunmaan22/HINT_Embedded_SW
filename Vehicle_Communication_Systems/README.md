# Vehicle Communication Systems

차량 도메인별 통신 요구사항, 네트워크 프로토콜, 프레임 해석과 임베디드 소프트웨어의 연결을 정리한 기술 노트이다. 각 기술은 **어떤 데이터를 전달하는지**, **시간과 오류를 어떻게 다루는지**, **다른 계층과 어떤 관계가 있는지**를 중심으로 설명한다.

## 3. 학습의 중심 질문

| 질문 | 연결되는 개념 |
|---|---|
| 어떤 기능이 데이터를 필요로 하는가 | 도메인·신호·서비스 |
| 얼마나 많이, 언제까지 전달해야 하는가 | 대역폭·전송시간·지연·지터 |
| 누가 먼저 보내는가 | CAN 중재·LIN 스케줄·FlexRay 슬롯·Ethernet 큐 |
| 받은 바이트는 무엇을 의미하는가 | 데이터베이스·비트 위치·엔디언·변환식 |
| 데이터가 정상이고 최신인가 | CRC·카운터·타임아웃·유효성 |
| 다른 네트워크로 어떻게 전달하는가 | 게이트웨이·라우팅·프로토콜 변환 |
| 언제 통신을 유지하거나 종료하는가 | 네트워크 관리·슬립·웨이크업 |

## 4. 출처와 정리 기준

사용자 제공 파일은 「차량통신시스템_이재욱.pdf」이며, PDF 2쪽 제목은 「자동차 통신 시스템」, 3쪽에는 **국립부경대학교 정보통신공학전공 류지열**이 기재되어 있다. 파일명과 본문 저자 표기가 달라 동일 인물로 단정하지 않고 두 표기를 구분하였다.

이 문서는 자료의 핵심 개념을 재서술한 학습 요약이다. 원문 문장·도판·사례 화면을 복제하지 않았으며, 실차 설정·제어 명령이나 실행 검증 결과를 제공하는 문서는 아니다. 강의의 속도·지연 예시는 특정 설계 조건의 예로 이해하고, 규격의 최신 판본이나 특정 차량의 보장값으로 일반화하지 않는다.
